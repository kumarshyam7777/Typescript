Learning AngularJS Module

This is a simple example of an AngularJS module.

AngularJS modules are containers for different parts of an application, such as controllers, services, directives, etc. They help in organizing the code and managing dependencies.

In this example, we have created a module named sampleApp using the angular.module method. This module can be used to define controllers, services, and other components that are part of the application.

To use this module in your application, you can include it as a dependency in other modules or use it to define components that belong to this module.

For more information on AngularJS modules, you can refer to the official documentation: AngularJS Modules Guide.
